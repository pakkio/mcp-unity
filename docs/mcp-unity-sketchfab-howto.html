STEP 15

Fixing glTF 270° X Root Rotation Vector Misalignment

▼
YOU
[Implied Physics Diagnosis]
💡 Context & Gloss: The glTFast importer left the root node with eulerAngles (270, 0, 0), causing transform.forward to point straight UP (0, 1, 0).
CLAUDE
Discovers root cause: CVRWheelHubController calculates speed via Vector3.Dot(transform.forward, velocity). Because forward pointed UP, vertical fall speed was measured as forward speed, zeroing engine torque curves.
Transform Realignment
1. Set root rotation to (0, 0, 0)
2. Set child GLTF node rotation to (90, 0, 0) (canceling pair, visual mesh stays stationary)
3. Recompute world positions for all wheel colliders & seats
UNITY
Root forward vector realigned to horizontal world space (0, 0, -1).
