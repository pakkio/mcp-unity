📖 Guida How-To per Utilizzare la Versione Pakkio

1

Installazione del Fork Pakkio su Unity

Nel Package Manager di Unity (o nel file Packages/manifest.json), aggiungi il riferimento alla repository taroccata:

"com.pakkio.mcp-unity": "https://github.com/pakkio/mcp-unity.git"
2

Usare il Tool set_sibling_index per Riordinare la Gerarchia

Mentre la versione standard fallisce nel riordinare gli oggetti fratelli, il tool di Pakkio consente di posizionare un oggetto prima o dopo un altro:

mcp-unity.set_sibling_index({ instanceId: 10452, insertBeforeInstanceId: 10480 })
3

Catturare Screenshot Visivi per l'AI Agent

Sfrutta il tool capture_screenshot per permettere all'AI di verificare visivamente la disposizione degli oggetti o i materiali applicati:

mcp-unity.capture_screenshot({ target: "SceneView", superSize: 2 })
4

Sfruttare il Ridisegno Automatico della Scena

Non occorre più interagire manualmente con l'Editor dopo ogni comando dell'AI: grazie al fix SceneView.RepaintAll() di Pakkio, l'interfaccia di Unity si aggiorna istantaneamente ad ogni tool call!
