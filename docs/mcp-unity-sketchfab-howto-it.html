PASSO 02

Gestione Pacchetto Git e Generazione dei File .meta Mancanti

▼
TU
[Screenshot errore di compilazione console Unity: CS0246]
💡 Contesto: Viene segnalato un errore CS0246: The type or namespace name 'ExportPackageTool' could not be found dopo aver aggiornato il package via Git.
CLAUDE
Unity ignora i file C# nei package Git che non hanno un file .meta associato. Generazione del GUID valido:
Comando PowerShell
powershell -Command "[guid]::NewGuid().ToString('N')"
Creato ExportPackageTool.cs.meta con GUID univoco. Commit applicato su repository.
UNITY
Compilation Successful: 0 errors, 0 warnings. Server MCP riavviato.
PASSO 03

Fix dell'Aggiornamento Grafico della Scena (Scene Repaint)

▼
TU
"quando aggiungi oggetti la vista di scena non si aggiorna subito"
💡 Contesto: L'utente nota che le modifiche inviate da MCP non ridisegnano istantaneamente la Scene View dell'Editor.
CLAUDE
Aggiunta della chiamata SceneView.RepaintAll() e EditorApplication.QueuePlayerLoopUpdate() al termine dell'esecuzione dei tool MCP in C#.
Modificato McpUnityServer.cs: ora la vista di scena si aggiorna in tempo reale.

PASSO 08

Algoritmo di Clustering Bounds per l'Identificazione delle Ruote

▼
TU
"i nodi del modello si chiamano tipo Object_47 e Circle.050_51... trova le 4 ruote"
💡 Contesto: I modelli di Sketchfab hanno spesso nomi di nodi generici ed anonimi. Occorre identificare matematicamente le 4 ruote.
CLAUDE
Esecuzione di un algoritmo di clustering basato su MeshRenderer.bounds:

Calcola il rettangolo delimitatore nello spazio globale per ciascun nodo foglia. Le ruote emergono come 4 volumi quasi cubici posizionati ai 4 angoli inferiori del bounding box dell'auto.

Identificate con precisione le 4 ruote tra oltre 120 nodi mesh anonimi!

PASSO 15

Fix della Rotazione a 270° del Modello glTF/GLB

▼
TU
"l'auto si ribalta appena entro in Play Mode!"
💡 Contesto: Gli asset glTF esportati da Blender presentano spesso una rotazione di 270° (-90°) sull'asse X per la conversione del sistema di coordinate (Z-up vs Y-up).
CLAUDE
Creazione di un nodo radice contenitore neutro con rotazione (0, 0, 0), separando la trasformazione fisica del Rigidbody dalla mesh orientata a 270°.
Stabilità fisica ripristinata: l'auto non sfarfalla più all'avvio.
